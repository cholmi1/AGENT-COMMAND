개인정보 처리방침

적용일: 2026년 10월 24일

1. 익명 계정과 브라우저 저장

AGENT-COMMAND는 Firebase 익명 인증을 사용합니다. 이메일이나 비밀번호를 입력하지 않아도 익명 식별자가 생성됩니다. 로그인 유지를 위해 식별자와 갱신 토큰을 이 브라우저의 저장소에 보관하며, API 요청에는 유효기간이 있는 인증 토큰을 사용합니다.

다른 기기나 브라우저에서는 별도 익명 계정이 생성됩니다. 브라우저 데이터를 삭제하면 기존 저장 기록에 접근하거나 직접 삭제하지 못할 수 있습니다. 필요한 기록을 복사하고, 불필요한 기록을 먼저 삭제해 주세요.

2. 기본으로 처리하는 이용 정보

서비스 연결과 하루 이용 한도 관리를 위해 익명 식별자, 요청 종류, 날짜, 이용 횟수 등 이용량 정보를 Firebase에 저장합니다. 이 정보는 기록 저장을 선택하지 않아도 처리됩니다. 서비스 운영·보안 과정에서 호스팅 제공업체의 접속 로그에 IP 주소와 요청 시각 등이 포함될 수 있습니다.

3. 선택한 경우에만 저장하는 기록

작성 화면에서 저장 항목을 체크하면 입력 내용, 선택 조건, 생성 결과, 작성 시각을 본인의 기록으로 Firebase Firestore에 저장합니다. 체크하지 않으면 입력과 결과를 기록에 저장하지 않습니다. 저장하지 않은 입력도 결과를 생성하기 위해 요청 처리 중 사용됩니다.

저장 목적은 본인이 이전 결과를 다시 확인하고 사용하는 것입니다. 공개 게시판, 광고, 강의 예시로 게시하지 않습니다. 상황·문제 설명에는 이름, 연락처, 금융정보, 비밀번호, API 비밀 키를 입력하지 마세요. API 키는 AI 설정의 전용 입력란에서만 입력하세요. 자동 가림 처리를 보장하지 않습니다.

4. 보관과 삭제

선택 저장한 기록은 사용자가 직접 삭제할 때까지 보관합니다. 1년 뒤 자동 삭제하는 정책은 없습니다. 작성 화면의 ‘내 저장 기록’에서 최근 20개를 확인하고 삭제할 수 있습니다. 삭제하면 해당 기록을 다시 불러올 수 없습니다. 이용 횟수 등 별도 운영 정보는 기록 삭제와 별개입니다.

5. 외부 서비스와 AI 처리

인증과 데이터 저장은 Google Firebase, 웹사이트와 API 제공은 Vercel을 사용합니다. 이들 서비스의 처리 위치와 운영 로그는 각 제공업체의 정책에 따릅니다.

처음에는 DeepSeek Flash가 선택되어 있지만 키 입력과 요금 동의 없이 외부 AI를 호출하지 않습니다. 사용자가 기본 규칙 모드를 선택하면 외부 AI를 호출하지 않습니다. 사용자가 OpenAI, Anthropic, DeepSeek 중 제공업체와 모델을 선택하고 본인의 API 키를 입력한 경우 외부 AI를 사용할 수 있습니다. 입력하거나 선택을 바꾸는 것만으로 연결 검사 또는 AI 호출을 하지 않습니다. 데이터 전송·사용 요금에 동의한 뒤 ‘지시서 만들기’ 또는 ‘도움말 보기’를 누를 때만 입력 텍스트, 관련 조건, API 키를 HTTPS로 이 서비스의 서버에 전송하고, 서버가 선택한 제공업체에 요청합니다. 해당 계정에 제공업체의 API 사용 요금이 발생할 수 있으며, 실패·중단된 요청도 이미 처리되었다면 요금이 발생할 수 있습니다.

API 키는 현재 탭의 입력란과 요청 처리 중 메모리에서만 취급합니다. 앱은 API 키를 브라우저의 localStorage·sessionStorage, URL·쿠키, 앱의 저장 기록이나 데이터베이스에 보관하지 않습니다. 키 지우기, 제공업체 변경, 페이지를 떠날 때 입력란의 키와 요금 동의를 지우며 새로고침 후 키를 다시 입력해야 합니다. 이 동작은 Firebase 익명 로그인을 유지하는 갱신 토큰 보관과 별개입니다. 브라우저·서버 메모리의 물리적 완전 삭제 시점을 보장하는 것은 아닙니다.

AI 데이터 전송·요금 동의와 입력·결과를 내 기록에 저장하는 동의는 별개입니다. 기록 저장을 선택해도 전용 입력란의 API 키는 기록에서 제외합니다. 외부 제공업체의 처리 위치, 보관, 이용 조건은 각 업체 정책을 확인하세요. 호스팅 인프라의 트래픽·보안 로그와 그 보관은 제공업체의 별도 정책에 따릅니다. 키가 의도치 않게 노출되었다면 제공업체에서 즉시 폐기하세요. 현재 도움말은 텍스트만 처리하며 이미지 분석을 제공하지 않습니다.

6. 이용 전 확인

생성 결과는 확인이 필요한 초안입니다. 실제 프로그램 실행, 유료 서비스 가입, 배포는 사용 중인 에이전트에서 별도로 결정하세요. 서비스 연결이 불가능하거나 이용 한도에 도달하면 요청이 제한될 수 있습니다.
