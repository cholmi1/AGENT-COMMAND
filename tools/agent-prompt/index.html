만들고 싶은 것은 있는데 데이터베이스 · 서버 · 배포를 몰라도 됩니다. 내 상황을 적고 메뉴만 고르면, AI 에이전트(클로드 코드 등)가 주도해서 끝까지 만들도록 시키는 지시서를 써 드립니다. 약 3분.

1. 내 상황과 만들고 싶은 것

사람 이름 · 회사 이름 · 연락처는 적지 않아도 됩니다. 적은 글은 지시서를 쓰기 위해 AI 회사로 전달됩니다. 아래 «남기는 데 동의»에 체크하면 남기고, 체크하지 않으면 저장하지 않습니다.

2. 필요한 것 고르기

모르겠으면 그대로 두세요. «에이전트가 골라 줘»로 두면 에이전트가 판단해서 하나만 추천합니다.

자료 저장 (데이터베이스)

서랍장입니다. 내 서비스가 기억해야 할 것(신청 내역 · 글 · 회원)을 넣어 두는 곳입니다. 이것이 없으면 새로고침할 때 사라집니다.

인터넷에 공개 (배포)

가게 문 열기입니다. 내 컴퓨터에서만 보이던 화면에 주소를 붙여, 다른 사람도 열 수 있게 하는 일입니다.

서버

화면 뒤에서 일하는 직원입니다. AI 부르기 · 결제 · 메일 보내기처럼 비밀 열쇠를 써야 하는 일을 맡습니다. 필요한지는 에이전트가 판단하도록 지시서에 적어 둡니다. 고를 것은 없습니다.
